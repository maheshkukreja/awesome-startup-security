# Contributing to Awesome Startup Security

Thank you for your interest in contributing! This list aims to be the go-to security resource for startup founders, CTOs, and engineering teams.

## Guidelines

### What makes a good addition?

- **Relevant**: Directly useful for startups building security practices
- **High quality**: Well-maintained, accurate, and from a reputable source
- **Accessible**: Prefer free/open-source resources, or those with startup-friendly pricing
- **Active**: The resource should be currently maintained and available

### What we're NOT looking for

- Enterprise-only tools with no startup-relevant pricing
- Resources behind hard paywalls with no free alternative
- Self-promotional content without genuine educational value
- Duplicate resources that cover the same ground as existing entries

## How to Contribute

1. **Fork** this repository
2. **Create a branch** (`git checkout -b add-resource-name`)
3. **Add your resource** in the appropriate section following the existing format
4. **Submit a pull request** with a clear description of what you're adding and why

### Format

Each entry should follow this format:

```markdown
- [Resource Name](https://example.com/) — Brief description (1-2 sentences) explaining what this is and why it's useful for startups.
```

- Use an em dash (—) to separate the link from the description
- Keep descriptions concise but informative
- End descriptions with a period
- Place new entries alphabetically within their section, or at the end if ordering is intentional

For the **Security Vendor Programs for Startups** table, add a row following the existing column format:

```markdown
| [Vendor Name](https://example.com/) | Category | Free tier / pricing info | Notes |
```

### Pull Request Checklist

- [ ] The link is working and points to the correct resource
- [ ] The resource is relevant to startup security
- [ ] The description is concise (1-2 sentences)
- [ ] The entry is placed in the correct section
- [ ] The entry follows the existing format
- [ ] No duplicate entries

## Suggesting New Sections

If you think a new section should be added, please open an issue first to discuss it. Include:

- The proposed section name
- Why it's relevant to startup security
- At least 3-5 resources that would go in it

## Reporting Broken Links

If you find a broken link, please open an issue or submit a PR with the fix. Include:

- The broken link
- A suggested replacement (if available)

## Code of Conduct

Be kind, constructive, and respectful. We're all here to help startups build better security.
